# 預算規劃器 · Budget Planner

單頁預算規劃工具（繁體中文 / TWD）：設定薪水與其他收入、套用分配模板、管理定期支出，資料存在瀏覽器 localStorage。

## 線上使用

https://qpalzm963.github.io/budget-planner/

## 本機開啟

直接開啟 `index.html`，或：

```bash
python3 -m http.server 8080
```

## 功能

- 多筆收入（薪水／獎金…）
- 分配模板：50/30/20、六罐子法、自訂（比例或固定金額）
- 甜甜圈圖＋超支警示
- 定期支出（每月／每 N 月／每年／每週）與「每月需預留」
- 未來 30 天到期清單
- 深淺色主題、JSON 匯出／匯入、重置

資料僅存在你的裝置，不會上傳到伺服器。
